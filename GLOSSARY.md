# jimmyreturnz portfolio

A personal portfolio site that presents its owner as a data scientist and developer first, and a rhythm-game player second, in a pastel vectorheart style.

## Visitor journey

**Intro**:
The game-like animation a visitor sees on their first visit, built from vectorheart elements. Always skippable; it ends as the Lobby.
_Avoid_: Splash, loading screen, opening

**Lobby**:
Everything before the Portfolio: profile, info, and the Enter button.
_Avoid_: Landing, home, title screen, gate

**Warp**:
The transition that morphs the visitor from the Lobby into the Portfolio. Moving between Portfolio pages uses lighter page transitions, not the Warp.
_Avoid_: Morph, enter animation

**Portfolio**:
Everything after the Lobby: a set of pages (Projects, Rhythm, TETR.IO, About, Community) sharing one header.
_Avoid_: Main page, dashboard

**Portfolio page**:
One page of the Portfolio, holding one or more Showcases.
_Avoid_: Tab, screen, section

**Page transition**:
The short animation when moving between Portfolio pages; the header and BGM stay put.
_Avoid_: Warp (that is Lobby → Portfolio only)

**Showcase**:
One self-contained block on a Portfolio page (e.g. osu!taiko, osu!mania, Skills, Shoutouts, Guestbook).
_Avoid_: Section, feature, widget

## Showcases

**Skills**:
The Showcase listing the owner's technical skills, each backed by evidence.
_Avoid_: Tech stack, skill bars

**Setups**:
The Showcase listing gaming gear and in-game settings.
_Avoid_: Loadout, gear, rig

**Shoutouts**:
The Showcase naming friends and people the owner respects, each with an optional quote.
_Avoid_: Credits, friends list, thanks

**Timeline**:
A secondary, scrollable history covering high school, university, internship, and career only.
_Avoid_: Journey, about timeline, level map

**Stats Card**:
A card showing the owner's public profile numbers from one platform (osu!, TETR.IO, or GitHub), refreshed daily.
_Avoid_: Profile widget, badge

**Guestbook**:
Where visitors leave short messages for the owner, in Thai, English, or Japanese, under any name they type.
_Avoid_: Comments, wall, chat

## Audio

**BGM**:
The background music that plays quietly in the Portfolio.
_Avoid_: Background song, theme music

**Feature audio**:
Any sound a Showcase plays (a chart's song, hitsounds, video audio); while it plays, BGM fades out.
_Avoid_: SFX (reserved for short interface sounds)

**SFX**:
Short interface sounds such as clicks, hovers, and the Warp.
_Avoid_: Hitsound (reserved for chart playback)
